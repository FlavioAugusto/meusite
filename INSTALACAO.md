# 🚀 Instalação Rápida - Google Maps Data Extractor

## ⚡ 3 Passos Simples:

### 1️⃣ Baixar os Arquivos
- Baixe todos os arquivos desta pasta para o seu computador
- Mantenha todos os arquivos na mesma pasta

### 2️⃣ Instalar no Chrome
1. Abra o Chrome
2. Digite `chrome://extensions/` na barra de endereços
3. Ative o **"Modo do desenvolvedor"** (canto superior direito)
4. Clique em **"Carregar sem compactação"**
5. Selecione a pasta com os arquivos da extensão
6. ✅ Pronto! A extensão aparecerá na barra de ferramentas

### 3️⃣ Como Usar
1. Vá para [Google Maps](https://maps.google.com)
2. Pesquise por empresas (ex: "restaurantes em São Paulo")
3. Clique no ícone 🗺️ da extensão
4. Clique em **"🚀 Iniciar Extração"**
5. Aguarde a coleta automática
6. Clique em **"📊 Baixar Excel"**
7. Abra o arquivo CSV no Excel/Sheets

## 📁 Arquivos Necessários:
- ✅ `manifest.json` - Configuração da extensão
- ✅ `popup.html` - Interface
- ✅ `popup.js` - Lógica principal
- ✅ `content.js` - Extração de dados
- ✅ `background.js` - Service worker
- ✅ `icon16.svg`, `icon48.svg`, `icon128.svg` - Ícones

## ❓ Problemas?
- Certifique-se de que todos os arquivos estão na mesma pasta
- Recarregue a extensão em `chrome://extensions/`
- Verifique se está numa página do Google Maps

## 🎯 Exemplo de Uso:
1. Pesquise "hotéis em Rio de Janeiro" no Google Maps
2. Use a extensão para extrair dados de todos os hotéis
3. Receba arquivo CSV com nome, rating, endereço, telefone, etc.
4. Abra no Excel para análise dos dados

**🔥 A extensão extrai automaticamente: nome, rating, avaliações, endereço, telefone, website, categoria e horários!**
